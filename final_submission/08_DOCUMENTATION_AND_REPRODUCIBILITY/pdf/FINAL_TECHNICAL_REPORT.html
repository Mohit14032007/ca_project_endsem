MoE Memory Wall: Predicting and Prefetching Experts for Faster LLM Inference

GitHub Repository: https://github.com/Mohit14032007/CA_Project.git | Git Baseline Anchor: d5bf61ff0c066c06f72173189f9924329f613a88 | Date: November 2026
ABSTRACT: Mixture-of-Experts (MoE) architectures decouple model parameter capacity from active per-token compute. However, off-chip parameter movement across bandwidth-constrained memory interfaces (e.g., DDR5) induces severe memory wall stalls (up to 98% of runtime). We present an architectural evaluation of training-free expert prediction (ST-MoE and CSTP) paired with asynchronous forward-lookahead prefetching, PABI quarantine, and Belady-style pinning.
